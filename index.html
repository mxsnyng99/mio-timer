📲 단축어 만들기 (한 번만)

  1. 단축어 앱 → + → 이름을 정확히 집중 루틴으로
  2. 텍스트 분할 추가 → 대상 '단축어 입력', 구분자 사용자 지정: ,
  3. 각 항목 반복 추가 (분할된 텍스트)
  4. 반복 안에 날짜 조정 → '현재 날짜'에 반복 항목 분 더하기
  5. 반복 안에 알람 생성 → 시간 '조정된 날짜', 레이블 집중 루틴
  6. 위에서 '📳 아이폰 알람으로 진동'을 켜면 끝. 화면이 꺼져 있어도 진짜 알람으로 울려요
